# 提出原稿の体裁

提出用にまとめた完成原稿を確認するときに適用する。
章の抜粋や執筆途中の本文には、タイトルや終端表示の不足を指摘しない。
応募先などの明示的な指定があれば、そちらを優先する。

- 一行目をタイトル、二行目を著者名、三行目を空行とし、四行目から本文を始める。
- 完成原稿はテキストファイルとし、ファイル名を `{著者名}_{タイトル}.txt` とする。著者名とタイトルには原稿の二行目と一行目の表記をそれぞれ用いる。
- 物語本編の最終行の次の行に `――了` を置く。ダッシュは `―`（U+2015）を二文字使う。
- 参考文献や引用文献がある場合は、`――了` のあとに置く。
- 参考文献は原則として `著者名、翻訳者名訳『書名』出版社名またはレーベル名、発行年` の順とする。訳者のない資料などは資料の種別に応じて扱い、存在しない要素を補わない。
- 文献は本文に直接使用したものを対象とする。引用関係を確かめる資料がなければ、使用の有無を断定しない。

ディレクトリ構成、ファイルの連結、出力先、提出フォルダはこのスキルでは指定しない。
