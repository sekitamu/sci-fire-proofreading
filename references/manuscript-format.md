# 原稿の表記ルール

Sci-Fire 式の原稿表記を既定値として使う。
対象作品に明示的な規則がある項目は、その規則を優先する。
これらは文字表現の規則であり、表示ソフトの動作を保証するものではない。

## 段落頭

- 台詞段落を除き、各段落の先頭に全角空白を一字入れる。
- 台詞段落は字下げせず、先頭に全角空白を入れない。
- 字下げが必要な段落では、表示上の字下げではなく、実際に全角空白が入っているか確認する。
- 空行や折り返し表示を段落の先頭と誤認しない。見出しや提出原稿のヘッダーは本文段落と区別する。

## 数字と英字

- 数字は原則として全角算用数字または漢数字を使う。
- 縦中横として扱う半角英数字が三文字以上なら、半角波括弧で囲む。例：`{123}`。
- 二文字までの半角文字は、この原稿方式では自動的に縦中横にする想定のため、波括弧は不要とする。
- 外国語の単語や文章は半角のままでよい。
- 外国語の略語やアルファベット一文字は、横倒しを避けるため全角にする。ただし明示された縦中横表記を除く。
- 半角英数字の存在だけでは違反としない。縦中横か外国語かなど、用途が判別できない場合は要確認とする。

## 記号

- 単独の感嘆符と疑問符には全角の `！` と `？` を使う。
- 縦中横の `!?` は半角二文字のままとし、波括弧は不要とする。
- 日本語文の括弧と記号は全角にする。ただし縦中横、ルビ、傍点、太字の専用記法を除く。
- 二文字のダッシュは `――`、四文字のダッシュは `――――` とする。使用文字は `―`（U+2015、HORIZONTAL BAR）。ダッシュの長さそのものを一律に変更する規則ではない。
- 縦書きの引用符は `“”` ではなく `〝〟` を使う。

## ルビと装飾

- ルビは `｜親文字《よみ》` の形とし、開始位置を示す全角縦線 `｜` を必ず入れる。例：`｜振《ふ》り｜仮名《がな》`。
- 傍点の範囲は二つずつの半角アンダースコアで囲む。例：`__傍点__`。
- 太字の範囲は二つずつの半角アスタリスクで囲む。例：`**太字**`。
- 装飾の区切りの欠落と、記号そのものの引用を区別する。創作上の当て字や意図的なルビを、読みが一般的でないという理由で誤りにしない。
